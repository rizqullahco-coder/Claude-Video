# Riz.co social captions

Every caption ends with the brand line: **Build Your Rizq. Don't Wait for It.**
- **Instagram:** the hook goes in line 1, because that's all that shows before "more". Keep 5–8 relevant hashtags at the end.
- **TikTok:** a short hook, the tagline and 3–5 hashtags. TikTok also reads the on-screen text and speech, so the caption can stay short.

### Posting tips
- **Instagram Reels:** pin a comment that asks the same question as the caption, so the conversation starts quickly.
- **Cover image:** use each video's thumbnail. TikTok lets you add a text cover, so use the video's hook line.
- **First 30 to 60 minutes:** reply to every comment. Early engagement helps the algorithm push the post.
- **Hashtags:** check `#rizco` and `#buildyourrizq` before using them. If another brand already uses them, pick something more specific.
