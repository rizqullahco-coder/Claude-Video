# AI for Accountants: Close Your Books Faster with Claude

A complete online course package by **BrightLedger Academy** (placeholder brand). You handle payment and hosting; everything else is here.

| Folder | What's in it |
|---|---|
| `01-outline/` | Course outline: outcomes, 4 modules, 19 lessons, quizzes with answers, capstone rubric, production plan |
| `02-videos/` | Lesson videos (MP4 1080p, burned-in captions) + `.srt` caption files. **Sample: Lesson 1.1** |
| `03-workbooks/` | Workbooks 1–4 and the Claude prompt pack (PDF, plus HTML source) |
| `04-datasets/` | Practice Excel files for the fictional Kopi Mesra Sdn Bhd (`_facts.json` = answer data) |
| `05-certificate/` | Certificate: blank PDF, sample PDF/PNG, and an editable HTML template (click the name to type, then print to PDF) |
| `06-overview-page/` | Sales/overview page: `index.html` to host on your site |
| `src/` | Scripts that rebuild everything (datasets, PDFs, videos) |

## Rebuilding

```bash
python3 course/src/make_datasets.py      # practice files + answer facts
python3 course/src/make_print.py         # workbooks, prompt pack, certificate (needs node + playwright)
VOICE_MODEL=/path/en-us-libritts-high.onnx python3 course/src/video/lesson_1_1.py /tmp/work   # sample video
```

Video needs ffmpeg, `pip install piper-tts numpy`, node with Playwright, and the Piper voice
`voice-en-us-libritts-high` (LibriTTS, CC BY 4.0, from the rhasspy/piper v0.0.2 GitHub release). Change the voice with
`VOICE_SPEAKER=<id>`.
