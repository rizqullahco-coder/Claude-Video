Practice company: Kopi Mesra Sdn Bhd (fictional). Name: ______________________________
Module 1 · Ledgers

Clean books fast

1.1 Issues list

I'm the accountant for Kopi Mesra Sdn Bhd, a café. The attached file is their March 2026 general ledger export.
Review it and list every issue you find: duplicate entries, missing account codes, missing references, inconsistent vendor names, and anything unusual.
Don't change the data yet.
Show the results as a table: row, reference, issue, suggested fix. Finish with total debits and total credits, and tell me anything you're unsure about.

1.1 Clean file

Thanks. Now create a cleaned version of the file:
• Use only accounts from the attached chart of accounts
• Add a column with the standard vendor name
• Flag duplicates, don't delete them
• Don't change any amounts
• Add a Status column: OK, Review, or Possible duplicate
Show total debits and credits before and after so I can tie out.

1.3 Vendor map

Group every vendor name in the attached ledger that refers to the same supplier (for example 'GRAB*FOOD 8812' and 'Grab Food MY').
Return a table: variant as written, standard name, suggested account code from the attached chart of accounts, confidence (high/medium/low).
Only use accounts that exist in the chart. List low-confidence matches separately for me to decide.

1.4 Duplicates and odd items

Check the attached ledger for: exact duplicates (same date, reference and amount), near duplicates (same amount and vendor within 3 days), missing references, round-sum amounts, weekend postings and anything posted to Suspense.
Don't delete anything. Give me a table: row, type of issue, why it's suspicious, what document I should check.

1.5 Anonymise

Before I share this file, list every column that may contain personal or sensitive data (names, IC numbers, phone numbers, bank account numbers, addresses). Suggest how to mask each one so the accounting analysis still works.

Module 2 · Closing

Reconcile a month

2.1 Month-end checklist

I close the books monthly for a two-outlet café with one bank account, delivery-platform sales, payroll and accruals. Build a month-end checklist in close order with columns: task, owner, due (working day 1-5), evidence to keep. Keep it to 20 tasks or fewer.

2.2 Bank rec matching

Attached are the March bank statement and the March cashbook. Match them using these rules, in order: 1) same amount, 2) date within ±3 days, 3) similar description.
Return three tables: matched items, items only in the bank, items only in the cashbook. Show closing balances from both files and the difference. Don't guess matches; list uncertain ones separately.

2.3 Reconciling items

For each unmatched item, classify it as: timing difference (unpresented payment or deposit in transit), bank-only item to record (charges, fees, interest), or error (amount or posting mistake). For errors, show the likely cause, e.g. transposed digits. Then prepare the bank reconciliation statement: balance per bank, ± timing differences = adjusted bank; balance per cashbook, ± adjustments = adjusted cashbook. They must agree.

2.4 Accruals and prepayments

Using the attached list of month-end items, draft journal entries for 31 March 2026. For each: date, debit account, credit account, amount, narrative, calculation. Use only accounts from the attached chart. Check that total debits equal total credits and show the check.

2.5 Close memo

Write a one-page month-end close memo for March 2026 using the information below. Sections: key balances, adjustments made, reconciliations completed, open items with owners, checks performed. Plain English, no more than 300 words. [paste your notes]

Modules 3–4 · Reports and capstone

Reports that read well

3.1 TB to statements

Map each account in the attached trial balance to the Profit & Loss or the Balance Sheet, grouped as: Revenue, Cost of sales, Operating expenses, Finance costs, Assets, Liabilities, Equity. Then produce a summarised P&L and balance sheet. Show that the TB balances and that profit agrees to the change in equity.

3.2 Variance analysis

Using the attached budget vs actual, flag variances bigger than RM 1,000 or 10%. For each, show: amount, %, favourable or adverse, and three possible business reasons I should confirm with the owner. Don't state reasons as facts.

3.3 Commentary

Write management commentary on the top three variances for the café owner. For each use: What happened (numbers), Why (only the reasons I confirm below), So what (impact on profit or cash), Now what (one action). Under 200 words, no jargon. Confirmed reasons: [paste]

3.4 Dashboard

Create a one-page dashboard for March from the attached data: revenue by channel (column chart), gross margin %, top 5 expenses (bar chart), budget vs actual for profit, and three key messages. Use clear labels and RM values.

3.5 Tailor

Rewrite this management report for [the café owner / a bank credit officer / the external auditor]. Keep all numbers identical. Change only emphasis, length and tone to fit the reader. [paste report]

4.x Capstone kickoff

I'm closing April 2026 for Kopi Mesra Sdn Bhd. Attached is the capstone pack. Read the README sheet and give me a step-by-step plan for the close, with the checks I should do after each step. Don't do the work yet.
